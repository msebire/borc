# borc

**Blank to Operational, Rejoin the Collective.**

*Resistance is futile.*

borc is a Windows-only tool that turns a blank machine into a ready-to-use
developer workstation. It describes the desired state of the machine with
WinGet Configuration (DSC v3) and uses PowerShell to apply it, so a fresh
install can be brought to a known, repeatable setup with a single run.
